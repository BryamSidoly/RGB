Simulador didático de LED endereçável

Modelo elétrico e lógico inspirado em WS2812B: fluxo serial → 24 bits consumidos por pixel → restante regenerado para o próximo.

Fita

Transmissão

Sequência de frames

Frame 0 / 0
Cada frame armazena o estado completo da fita. Edite os LEDs normalmente e use "Adicionar frame" para criar uma nova posição na animação.
WS2812B típico: 800 kbit/s. Cada pixel recebe 24 bits (3 bytes). A ordem de bytes é configurável abaixo.

Fonte e cobre

Modelo resistivo simplificado: queda de tensão = I × R. Para uma fita real, resistência depende do trilho, cobre, geometria e pontos de injeção.

Interação

Arraste a fita no espaço central. Clique em um pixel para selecioná-lo. Roda do mouse = zoom. O LED selecionado pode ser editado diretamente no painel direito.
Fluxo: DIN → LED 1 → LED 2 → ... → DOUT

O Shift Register representa os bits que chegam pela entrada DATA. O Latch representa a memória que mantém os valores depois da transferência. O PWM transforma cada byte armazenado em um duty entre 0% e 100%.

Decomposição do fluxo

O primeiro CI pega exatamente 24 bits do início do fluxo e coloca o restante no DOUT. Não existe endereço explícito no protocolo básico.
